# GEMINI.md

Google Gemini compatibility shim for this reusable harness framework.

## Purpose

This file exists for repositories and tools that expect a root GEMINI.md.
The canonical workflow contract remains in AGENTS.md.

## Startup

1. Read AGENTS.md.
2. Read feature_list.json.
3. Read PROGRESS.md.
4. Run ./init.sh.

## State Files

- feature_list.json
- PROGRESS.md (canonical)
- DECISIONS.md
- session-handoff.md

## Verification

Use make check (or npm run check) before claiming completion.
