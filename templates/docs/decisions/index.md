# Decision Records

Expanded architectural decision records live here. The canonical, always-current log is [`DECISIONS.md`](../../DECISIONS.md) at the repository root.

Each record follows the template in `DECISIONS.md`:

```
### D-XXX: [Decision Title]

**Date:** YYYY-MM-DD
**Status:** proposed | accepted | deprecated | superseded by D-YYY
**Context:** ...
**Decision:** ...
**Alternatives considered:** ...
**Consequences:** ...
```

Decisions that grow beyond a few paragraphs in `DECISIONS.md` should be expanded into a dedicated file here and linked from the log entry.
